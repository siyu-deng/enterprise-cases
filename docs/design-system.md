# 企业 AI 落地观察设计系统 · v0.2

可查看入口 /design-system。样式真源 src/app/globals.css；共享组件 src/components/ui.tsx；本文件解释设计职责，不另建数值副本。

依据用户于 2026-11-03 的方向修订：保留熟悉的三列资料浏览结构，使用接近 Apple 网页的简洁排版、系统字体、克制的蓝色、白/浅灰表面与充足留白。平台拥有自己的名称与标识，不使用 FastGPT、Apple 的品牌或营销资产。

## 信息与布局

- 单一任务：发现资料、理解概要、回到来源。移除咨询表单、客户墙、营销统计、点赞、人气和悬浮营销入口。
- 导航、首屏、搜索、类型、行业、卡片、来源区按顺序组织。副文只交代摘要与原始出处。
- 桌面三列，平板两列，手机单列；标题完整换行，概要在卡片截为三行，弹窗展示全部已保存摘要。
- 图片只作原始来源配图，预留稳定比例，不暗示为已验证的真实实施现场。
- 企业案例与场景参考用稳定文字标签区分，不使用共创带或交付背书。
- 表单只有搜索与筛选；加载、空结果、错误、媒体失败在同一体系展示。

## 复用

保留现有 Next.js、Lucide 图标与 Radix Dialog（焦点、Escape、关闭）。原生按钮、输入、选择器配合薄共享组件；本期不引入另一套组件主题。移除 POC 按钮变体、失效咨询组件与所有未使用旧样式，避免维护两套体系。
